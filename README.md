# cache

Cache manager for Eudoxys packages

# Documentation

See https://www.eudoxys.com/cache

# Installation

Install using Eudoxys Package Manager:

    pip install --upgrade git+https://github.com/eudoxys/epm
    epm install cache

Install using `pip`:

    pip install git+https://github.com/eudoxys/cache

# Maintenance

## Update docs

    make docs

Documentation is generated by pdoc into `docs/` (not checked in) and is
published to GitHub Pages by the `deploy-pages.yaml` workflow on each push to
`main`.

## Run tests

    make test

or

    pip install -e . pytest
    pytest

One test downloads a small file from the WECC archive; skip it with
`pytest -m "not network"`. See [`cache/_test/README.md`](cache/_test/README.md).
